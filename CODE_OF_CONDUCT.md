# Code of Conduct

BugTrail follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be patient, assume good intent, and focus on what is best for the people using and building BugTrail. Harassment, personal attacks and discriminatory language are not tolerated in issues, pull requests, discussions or any other project space.

If you experience or witness unacceptable behaviour, contact a maintainer privately through their GitHub profile. Reports are handled confidentially.
