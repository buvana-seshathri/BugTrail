# Security Policy

BugTrail reads network and console activity of the tab being investigated, so we take security and privacy issues seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's [private vulnerability reporting](https://github.com/buvana-seshathri/BugTrail/security/advisories/new) instead. Include steps to reproduce and the impact you see. We aim to acknowledge reports within a few days.

Examples of what we want to hear about:

- data leaving the browser without the user explicitly copying or exporting it;
- secrets surviving redaction in a copied report or cURL command;
- a web page being able to read or influence BugTrail's recordings.
